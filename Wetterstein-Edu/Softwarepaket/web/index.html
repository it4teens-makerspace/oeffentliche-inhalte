Wetterstation auf den ESP flashen

ESP8266 (NodeMCU) per USB-Kabel anschliessen – ein reines Ladekabel ohne Datenadern funktioniert nicht. Dann die beiden Schritte nacheinander ausfuehren.

Schritt 1 – Firmware aufspielen

Auf Verbinden klicken, im Browser-Dialog den seriellen Port des ESP auswaehlen (meist „CH340“ oder „CP210x“), dann „Install Wetterstation“ waehlen. Dauert ein bis zwei Minuten.

Dieser Browser unterstuetzt kein Web Serial. Bitte Chrome oder Edge auf einem Desktop-Rechner verwenden. Die Seite muss ueber https geoeffnet werden.

Schritt 2 – WLAN und Ort uebertragen

Nach dem Flashen hier die Zugangsdaten eintragen und senden. Sie gehen ueber dasselbe USB-Kabel an die Wetterstation und werden dort dauerhaft gespeichert.

Format: Ort,Laendercode – z. B. Aachen,de, Wien,at oder New York,us

Deine Daten bleiben bei dir. Diese Seite besteht nur aus statischen Dateien, es gibt keinen Server, der etwas entgegennimmt. WLAN-Name und Passwort verlassen den Browser ausschliesslich ueber das USB-Kabel zur Wetterstation.

Voraussetzungen: Chrome, Edge oder Opera auf Windows, macOS oder Linux. Firefox, Safari, iPhone und Android koennen kein Web Serial. Unter Windows ist evtl. der USB-Treiber CH340 bzw. CP210x noetig.

Klappt Schritt 2 nicht, geht es auch ohne: Die Wetterstation oeffnet das WLAN Wetterstation-Setup (Passwort wetter1234). Damit verbinden und die Daten auf der Seite 192.168.4.1 eintragen.
