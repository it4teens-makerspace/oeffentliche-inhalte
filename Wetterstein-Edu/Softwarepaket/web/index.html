Wetterstation auf den ESP flashen

  1. ESP8266 (NodeMCU) per USB-Kabel an den Rechner anschliessen – ein Ladekabel ohne Datenadern funktioniert nicht.
  2. Auf Verbinden klicken und im Browser-Dialog den seriellen Port des ESP auswaehlen (meist „CH340“ oder „CP210x“).
  3. „Install Wetterstation“ waehlen und warten, bis der Vorgang abgeschlossen ist (ca. 1–2 Minuten).
  4. Danach oeffnet die Wetterstation das WLAN Wetterstation-Setup (Passwort wetter1234). Damit verbinden – die Setup-Seite oeffnet sich automatisch, sonst 192.168.4.1 aufrufen – und dort das eigene WLAN sowie den Ort fuer die Wettervorhersage (z. B. Aachen,de) eintragen.
Dieser Browser unterstuetzt kein Web Serial. Bitte Chrome oder Edge auf einem Desktop-Rechner verwenden. Die Seite muss ueber https geoeffnet werden.
Voraussetzungen: Chrome, Edge oder Opera auf Windows, macOS oder Linux. Firefox, Safari, iPhone und Android werden nicht unterstuetzt, da sie kein Web Serial koennen. Unter Windows ist evtl. der USB-Treiber (CH340 bzw. CP210x) noetig.
